# 存档系统重构完整文档

## 📊 当前存档系统架构分析

### 问题诊断

你的项目中存在**双存储系统**，导致数据不同步：

| 数据类型 | SaveManager (JSON) | FansDataManager (PlayerPrefs) |
|---------|-------------------|------------------------------|
| 粉丝总数 | `SaveData.totalFans` | `PlayerPrefs["TotalFans"]` |
| 解锁章节 | `SaveData.unlockedChapter` | `PlayerPrefs["ChapterProgress"]` |
| 关卡进度 | `SaveData.levelProgress` | ❌ |
| 剧情进度 | `SaveData.storyProgress` | ❌ |
| 游戏设置 | `SaveData.settings` | ❌ |

### 数据流向问题

```
游戏运行时：
  PlayDataCollector.SaveResult()
    ↓
  FansDataManager.AddFans()  →  PlayerPrefs 写入
    ↓
  SaveManager.SaveLevelResult()
    ↓
  SaveManager.SyncCurrentSettings()
    ↓
  从 FansDataManager 读取  →  写入 SaveData.totalFans
    ↓
  保存 JSON 文件
```

**问题：**
1. 粉丝数据先写入 PlayerPrefs，再同步到 JSON
2. 如果中途崩溃，两个系统数据不一致
3. `ClearGameProgressKeepSettings()` 需要同时清除两个系统
4. `HasGameProgress()` 只检查 JSON，不检查 PlayerPrefs

---

## ✅ 重构方案：统一使用 SaveManager

### 方案概述

**目标：** 将所有数据统一由 SaveManager 管理，FansDataManager 改为纯计算/查询类

**原则：**
- SaveManager 是唯一的数据持久化入口
- FansDataManager 只负责业务逻辑（计算、查询）
- 所有数据读写都通过 SaveManager

## 🔧 重构步骤

### 第1步：重构 FansDataManager

将其改为**无状态的工具类**，所有数据从 SaveManager 读取：

```csharp
/// <summary>
/// 粉丝数据管理器（重构版）
/// 纯业务逻辑类，不负责数据持久化
/// 所有数据从 SaveManager 读取
/// </summary>
public static class FansDataManager
{
    /// <summary>
    /// 获取当前粉丝总数
    /// </summary>
    public static long GetTotalFans()
    {
        if (SaveManager.Instance == null) return 0;
        return SaveManager.Instance.GetTotalFans();
    }

    /// <summary>
    /// 增加粉丝数
    /// </summary>
    public static void AddFans(long fansToAdd)
    {
        if (SaveManager.Instance == null)
        {
            Debug.LogError("[FansDataManager] SaveManager not found!");
            return;
        }

        long currentFans = SaveManager.Instance.GetTotalFans();
        long newFans = currentFans + fansToAdd;
        SaveManager.Instance.SetTotalFans(newFans);

        Debug.Log($"[FansData] Added {fansToAdd} fans. Total: {currentFans} -> {newFans}");

        // 检查是否解锁新章节
        CheckAndUnlockChapters();
    }

    /// <summary>
    /// 获取当前解锁的章节
    /// </summary>
    public static int GetUnlockedChapter()
    {
        if (SaveManager.Instance == null) return 0;
        return SaveManager.Instance.GetUnlockedChapter();
    }

    /// <summary>
    /// 检查是否解锁指定章节
    /// </summary>
    public static bool IsChapterUnlocked(int chapterIndex)
    {
        long totalFans = GetTotalFans();

        switch (chapterIndex)
        {
            case 0: return true;
            case 1: return totalFans >= 1000000;
            case 2: return totalFans >= 10000000;
            default: return false;
        }
    }

    /// <summary>
    /// 获取下一章节解锁所需粉丝数
    /// </summary>
    public static long GetRequiredFansForNextChapter(int currentChapter)
    {
        switch (currentChapter)
        {
            case 0: return 1000000;
            case 1: return 10000000;
            case 2: return long.MaxValue;
            default: return 0;
        }
    }

    /// <summary>
    /// 检查并解锁新章节
    /// </summary>
    private static void CheckAndUnlockChapters()
    {
        if (SaveManager.Instance == null) return;

        long totalFans = GetTotalFans();
        int currentUnlocked = GetUnlockedChapter();

        for (int i = currentUnlocked + 1; i <= 2; i++)
        {
            if (IsChapterUnlocked(i))
            {
                SaveManager.Instance.SetUnlockedChapter(i);
                Debug.Log($"[FansData] Unlocked chapter {i + 1}");
            }
            else
            {
                break;
            }
        }
    }

    /// <summary>
    /// 格式化粉丝数显示
    /// </summary>
    public static string FormatFansCount(long fans)
    {
        return ScoreCalculator.FormatLargeNumber(fans);
    }
}
```

```csharp
public void SaveLevelResult(string levelName, string songName, ChartDifficulty difficulty,
    int score, string rank, int perfect, int great, int good, int miss, int maxCombo, long fansEarned)
{
    var progress = GetLevelProgress(levelName, songName, difficulty);

    if (progress == null)
    {
        progress = new LevelProgressData
        {
            levelName = levelName,
            songName = songName,
            difficulty = difficulty
        };
    }

    // 更新数据
    progress.isCleared = true;
    progress.playCount++;
    progress.lastPlayedTime = DateTime.Now.ToString("yyyy-MM-dd HH:mm:ss");

    if (score > progress.highScore)
    {
        progress.highScore = score;
        progress.rank = rank;
        progress.bestPerfectCount = perfect;
        progress.bestGreatCount = great;
        progress.bestGoodCount = good;
        progress.bestMissCount = miss;
        progress.bestMaxCombo = maxCombo;
    }

    progress.fansEarned += fansEarned;
    UpdateLevelProgress(progress);

    // 直接更新粉丝数（不通过 FansDataManager）
    AddFans(fansEarned);

    Debug.Log($"[SaveManager] Level result saved: {levelName} - {difficulty}, Score: {score}, Rank: {rank}");
}
```

## 📝 迁移 PlayerPrefs 数据

为了不丢失玩家现有数据，需要在首次加载时迁移：

```csharp
// 在 SaveManager.LoadGame() 中添加

private void LoadGame()
{
    if (File.Exists(saveFilePath))
    {
        try
        {
            string json = File.ReadAllText(saveFilePath);
            currentSaveData = JsonUtility.FromJson<SaveData>(json);
            
            // 迁移旧数据（仅首次）
            MigrateFromPlayerPrefs();
            
            ApplySettings();
        }
        catch (Exception e)
        {
            Debug.LogError($"[SaveManager] Failed to load save file: {e.Message}");
            CreateNewSave();
        }
    }
    else
    {
        CreateNewSave();
    }
}

private void MigrateFromPlayerPrefs()
{
    // 检查是否已迁移
    if (PlayerPrefs.GetInt("DataMigrated", 0) == 1)
        return;

    // 从 PlayerPrefs 读取旧数据
    string fansString = PlayerPrefs.GetString("TotalFans", "0");
    if (long.TryParse(fansString, out long oldFans) && oldFans > currentSaveData.totalFans)
    {
        currentSaveData.totalFans = oldFans;
        Debug.Log($"[SaveManager] Migrated fans data: {oldFans}");
    }

    int oldChapter = PlayerPrefs.GetInt("ChapterProgress", 0);
    if (oldChapter > currentSaveData.unlockedChapter)
    {
        currentSaveData.unlockedChapter = oldChapter;
        Debug.Log($"[SaveManager] Migrated chapter data: {oldChapter}");
    }

    // 标记已迁移
    PlayerPrefs.SetInt("DataMigrated", 1);
    PlayerPrefs.Save();

    // 保存迁移后的数据
    SaveGame();
}
```
