# Chart Editor 判定线和判定系统设置指南

## 判定线设置

### 方法1：使用Sprite（推荐）

1. 创建空GameObject，命名为 `JudgmentLine`
2. Position设置为 `(0, -4, 0)` （与游戏模式一致）
3. 添加 `SpriteRenderer` 组件
4. 设置Sprite为一条横线（或使用纯色方块拉伸）
5. 设置颜色为醒目的颜色（如白色、黄色）
6. 设置Scale为 `(10, 0.1, 1)` 使其横跨所有lane
7. 设置Sorting Layer确保在note之下

### 方法2：使用LineRenderer

1. 创建空GameObject，命名为 `JudgmentLine`
2. Position设置为 `(0, -4, 0)`
3. 添加 `LineRenderer` 组件
4. 设置起点和终点：`(-5, 0, 0)` 到 `(5, 0, 0)`
5. 设置宽度为 `0.1`
6. 设置颜色为白色或黄色

### 重要：判定线不移动

- 判定线固定在世界坐标 `Y = -4`
- 镜头向上移动，note向下经过判定线
- 判定线**不是**Camera的子物体（否则会跟着镜头移动）

## 判定系统

### Chart Editor中的判定

**重要区别**：Chart Editor和游戏模式的判定不同

| 特性 | 游戏模式 | Chart Editor模式 |
|------|---------|-----------------|
| 判定触发 | 玩家按键 | 播放时自动判定 |
| Note消失 | 判定后消失 | 永不消失 |
| 判定音效 | 按键时播放 | 经过判定线时播放 |
| 目的 | 游玩 | 预览谱面 |
