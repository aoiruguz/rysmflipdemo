# 第四关开场剧情触发说明

## 剧情ID
`Level_04_Opening`

## 触发方式

### 方法1：在关卡开始时触发（推荐）

在第四关的场景初始化代码中调用：

```csharp
using UnityEngine;

public class Level04Initializer : MonoBehaviour
{
    void Start()
    {
        // 播放开场剧情
        AVGStoryManager.Instance.CheckAndPlayStory("Level_04_Opening", () =>
        {
            // 剧情播放完成后，开始关卡
            StartLevel();
        });
    }

    void StartLevel()
    {
        // 开始关卡的逻辑
        Debug.Log("第四关开始！");
    }
}
```

### 方法2：使用StoryTrigger组件

1. 在第四关场景中创建空物体，命名为 `StoryTrigger_Level04`
2. 添加组件：`StoryTrigger.cs`
3. 配置Inspector：
   - `Story Id` = `Level_04_Opening`
   - `Trigger Moment` = `OnStart`
   - `Trigger Once` = ✅
4. 在 `On Story Complete` 事件中添加关卡开始的逻辑

### 方法3：从大地图进入时触发

如果玩家从大地图点击第四关进入，可以在场景加载完成后触发：

```csharp
using UnityEngine;
using UnityEngine.SceneManagement;

public class LevelSelector : MonoBehaviour
{
    public void OnLevel04ButtonClicked()
    {
        // 加载第四关场景
        SceneManager.LoadScene("Level_04");
        
        // 场景加载完成后触发剧情
        SceneManager.sceneLoaded += OnLevel04Loaded;
    }

    void OnLevel04Loaded(Scene scene, LoadSceneMode mode)
    {
        if (scene.name == "Level_04")
        {
            SceneManager.sceneLoaded -= OnLevel04Loaded;
            
            // 播放开场剧情
            AVGStoryManager.Instance.CheckAndPlayStory("Level_04_Opening", () =>
            {
                Debug.Log("第四关剧情播放完成");
            });
        }
    }
}
```

## 资源准备

### 需要准备的图片资源：

将以下文件放入 `Assets/Resources/` 文件夹：

```
Assets/Resources/
├── 小猫.png                    # 角色立绘
└── 第四关1.png                 # 背景图1
└── 第四关2.png                 # 背景图2
└── 第四关3.png                 # 背景图3
└── 第四关4.png                 # 背景图4
└── 第四关5.png                 # 背景图5
```

**注意：** 
- 文件名必须与JSON中的路径完全一致
- 如果文件在子文件夹中，JSON路径也要包含文件夹名
- 例如：`Assets/Resources/Characters/小猫.png` → JSON中填写 `"Characters/小猫"`

## 推荐触发流程

```
玩家点击第四关
    ↓
加载第四关场景
    ↓
场景Start时触发剧情
    ↓
播放5句开场对话（自动切换背景）
    ↓
剧情结束回调
    ↓
开始关卡游戏逻辑
```

## 测试方法

1. 确保 `AVGStoryManager` 存在于场景中（或设置为DontDestroyOnLoad）
2. 确保 `StoryPlayer` UI已创建并关联
3. 将资源文件放入正确位置
4. 运行第四关场景
5. 观察剧情是否正常播放

## 如果剧情不播放

检查Console日志：
- `[AVGStoryManager] 未找到storyId为"Level_04_Opening"的剧情数据` → JSON文件未正确加载
- `[AVGStoryManager] 场景中未找到StoryPlayer组件！` → StoryPlayer未创建或未关联
- `[StoryPlayer] 未找到背景图：第四关1` → 资源文件路径不正确

## 让剧情每次都播放

如果你希望每次进入第四关都播放这段剧情（而不是只播放一次），使用：

```csharp
AVGStoryManager.Instance.ForcePlayStory("Level_04_Opening", () =>
{
    StartLevel();
});
```
